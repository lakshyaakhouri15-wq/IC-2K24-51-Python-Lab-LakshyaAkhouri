# Lab 4 — Section A: Before You Start

1. **What can make one program faster than another if both give the same result?**

   A program can be faster when it performs fewer operations and avoids repeating work. The algorithm matters more than the number of lines of code.

2. **Name a Python feature that helps prevent writing the same code again.**

   A function helps avoid repetition. We can place reusable instructions inside a function and call it whenever they are needed.
