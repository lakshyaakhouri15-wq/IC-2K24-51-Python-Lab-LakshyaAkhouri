# Python Dictionaries – Lab 5 (Part C)

## Summary
Part C covers eight conceptual and reasoning questions with worked Python examples focused on dictionary internals, safe mutation, comprehensions, and lookup performance.

## Key Concepts Covered
- Reference assignment vs. shallow copy vs. deep copy
- Key hashability rules and valid key types
- Direct indexing (`[]`) vs. safe lookup (`.get()`)
- Single-key assignment vs. bulk updates with `.update()`
- Non-destructive transformations using dictionary comprehensions
- Safely deleting entries during iteration
- Inverting one-to-many mappings (`setdefault`)
- Time complexity comparison ($O(1)$ hash lookup vs. $O(n)$ list scan)
